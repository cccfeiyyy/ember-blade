## 1. 试玩方法与样本

- **样本 A（剧情流程）**：自动化完成 标题 → 初始祝福 → 第 1 波 → 波次间祝福 → 第 4/5 波 → Boss（50% 二阶段、25% 狂怒）→ 胜利结算 → 再战/返回标题。
- **样本 B（无尽）**：剧情胜利后进入无尽（第 6 波起），连续清波至第 9 波死亡结算；第二局至第 11 波；刷新验证纪录持久化。
- **样本 C（针对性操作）**：格挡/精准弹反时序、处决、精英词缀、爆裂者、掉落拾取、暂停设置；每项均保留截图与状态数据。
- 说明：为压缩时间，部分流程使用调试接口（`skipToBoss`、`killAll`、`god`、`damageEnemyById`）推进；凡受调试接口影响的数值（得分/评级/到达波次耗时）均在文中标注，不作为真人难度结论。

## 2. 核心循环与节奏观察

1. **循环清晰**：清波 → 1.6s 后「选择回响」三选一 → 继续下一波；每波结束恢复/进入新波，节奏与 v1 的「战斗—清波—强化」循环衔接自然。
2. **开局引导**：标题页即给出完整操作表（WASD/鼠标/左键/右键/SPACE/E/F/R/TAB/ESC），并新增 Q「格挡·精准弹反」与「1/2/3 选择回响」提示；新玩家能在开战前了解核心动作。
3. **祝福节奏**：初始 1 次 + 每波清场 1 次（无尽每波 1 次）。卡牌界面在战斗上方半透明展开，战斗冻结但保留氛围；0.45s 选择动画后恢复，停顿感可接受。
4. **波次压力**：第 1 波 3 个蚀影，第 4 波开始出现爆裂者、第 5 波 Boss 与爆裂者混编；既有战斗时长（自动化观察 8–20s/波，调试清怪除外）与新增敌人威胁度需要在真人试玩中确认是否有「一波过长」问题。

## 3. 构筑（回响祝福）体验

- **选项可读性好**：每张卡包含 稀有度徽标（普通/稀有/史诗）、图标字（韵/荆/命等）、名称、数值化效果（如「完美闪避/弹反后 3 秒内攻击伤害 +50%」「受到伤害时反弹 14 点伤害」「生命上限 +25，立即回复 25」）与风味文案；三张卡信息层级清晰。
- **选择方式**：鼠标点击与键盘 `1/2/3` 均可用；卡牌有序号提示，HUD 底部会累积已获得祝福 chip。
- **构筑差异可感知**：数值型祝福可通过 `state().mods`/`maxHp` 直接观测（如「不屈」使生命上限 100→125），说明祝福不是纯文本装饰；建议真人在 2–3 局中体验「连击流 / 弹反流 / 处决流」三条路线的成型速度与强度差。
- **潜在问题（主观）**：初始三选一的稀有度以普通为主，首局构筑感偏平；若希望更快进入「质变」，可考虑首轮提高稀有保底或在后续版本增加「重掷/跳过」选项（当前版本无跳过，属设计选择，非缺陷）。

## 4. 战斗动作与反馈

| 动作 | 观察 |
| --- | --- |
| 轻斩三连 | 命中反馈（伤害数字、连击数、风格分）明显；三段连击可稳定衔接，清小怪效率高 |
| 重斩 | 体力消耗明显（100→70），高伤害 + 硬直；资源压力让重斩有取舍 |
| 闪避 | 无敌帧可稳定规避伤害（对照组无无敌帧正常掉血）；完美闪避联动「完美余音」类祝福 |
| **格挡（Q 按住）** | 进入 `block` 状态、HUD 技能位可用；正面受击 20 伤害 → 6（-70%），体力 99.8→83.8；格挡反馈（火花/音效/镜头微震）到位 |
| **精准弹反（0.2s 窗口）** | 在敌人攻击命中帧前按 Q 成功：敌人进入硬直、HUD 显示「完美弹反」与评级提示、得分/势能/风格齐涨；失败退化为普通格挡，风险回报结构成立 |
| 剑气（E） | 远程穿透、体力 25、冷却 3.2s；对浮空/远处敌人有明确用途 |
| 烬灭（F） | 势满释放，释放瞬间势清空（最终构建 100→0）、范围伤害 + 慢动作 + 大范围特效，爆发感强 |
| 饮烬（R） | 回复 40 HP、消耗药剂，动作期间可被打断的风险让回血时机成为决策点 |
| **处决** | 低血量敌人出现可处决提示（敌人血条 exec 状态）；近战命中触发处决动画、目标即死、回血 +6、得分/风格与统计增加；「打至破绽→处决」的收割循环成立 |
| **风格评级 D→S** | HUD 右上角字母 + 进度条 + 倍率，实时升降；受击 -10、无事件 2.6s 后衰减、达阈值播放升/降级音效与称号提示；是「打得好→倍率高」的可见正反馈 |

**体感观察（自动化）**：脚本化连续战斗下风格分从 4 → 100（D→S）约需十余秒高频输出，S 级较易达到；结合倍率 ×1.5 的收益，建议真人复核 S 级的维持难度是否偏低（可作为后续调参项，非缺陷）。

## 5. Boss「无面守望者」二阶段

1. **阶段演出**：HP 50% 时触发二阶段——HUD 名称变为「回响之主 / 回响形态 · 第 2 阶段」，音乐切到 `boss2`，场景从冷蓝色（背景 `#05070d`）变为赤红（背景 `#160409`、雾 `#24060a`，红色 Hemisphere/Point 光），压迫感明显；25% 进入「终焉形态 / 终焉守望者」（狂怒，速度与前摇提升）。
2. **新增攻击**（120s 采样全部出现）：
   - **剑雨 `swordrain`**：多段落剑/落点预警，需走位；
   - **三连冲击波 `shock3`**：三环依次扩散，节奏清晰；
   - **突进 `charge`**：远距离直线突进，可侧闪/格挡，是二阶段最高收益反击窗口之一；
   - 另有 `sweep3/overhead/summon` 等基础招式混编，召唤会引入精英。
3. **可读性**：预警圈/扇形与地面颜色区分明显（赤红环境下仍可辨）；HUD Boss 血条与阶段名清晰，二阶段有短暂转场无敌窗口，避免玩家被转场秒杀。
4. **主观建议**：赤红场景在截图中偏暗（尤其小屏），建议真机确认敌人与预警在红色背景上的对比度；剑雨/冲击波的「必须走位」提示可以再强化音效/地面亮度。

## 6. 无尽模式

- **入口与节奏**：剧情胜利结算 →「无 尽 回 响」→ 第 6 波开始；死亡结算显示「回 响 止 步」、到达波次、得分与评级（按波次 9 → B），并有「再 入 无 尽」直接重开。
- **难度观察**：无尽头目数/血量随波次增长（GDD：hpMul/dmgMul/精英概率上升、每 5 波 Boss）；自动化实测第一局到第 9 波、第二局到第 11 波（调试清怪，不能代表真人耗时/难度）。建议真人试玩 6–15 波评估曲线是否平滑、精英/爆裂者密度是否过高。
- **纪录系统**：localStorage 最高纪录（无尽波次 + 得分 + 通关次数）在标题页展示，跨刷新保留；新纪录只增不减；坏数据容错不崩。表现符合设计。
- **潜在问题（主观）**：结算评级仅按到达波次（无尽 B 档 7–9 波），与「风格表现」的综合评级在体验上未体现；若希望鼓励高质量操作，可考虑加入风格/无伤等维度（设计建议，非缺陷）。

## 7. 精英 / 爆裂者 / 掉落

- **精英词缀**：护盾（HP×1.7、1 层护盾）、狂怒（HP×1.5、速度 1.15、伤害提升）、迅捷（HP×1.35、速度 1.4）三种，均有光环与 HUD 提示；击败必掉资源，作为「优先击杀目标」的目标感成立。
- **爆裂者**：接近后 0.85s 蓄力 + 地面预警圈 + 滴答音效，自爆 26 伤害并产生势能掉落；「先杀/拉开/格挡无效（地面 AOE）」的威胁定位清晰，建议真人在混战中确认预警是否足够醒目。
- **掉落**：光球自带磁吸（约 5m 内飞向玩家），治疗 +10、势能 +18，拾取有清脆音效与 HUD 反馈；混战中拾取的满足感较好。

## 8. UI / UX 观察

- **HUD**：左上得分/用时、中上波次、右上连击与风格（字母+倍率+进度条）、左下生命/体力/药剂、右下势能与技能位（Q/SPACE/E）——信息分区合理，战斗画面中央保持干净；风格字母与 Boss 血条阶段名在截图中清晰。
- **标题页**：氛围文字 + 操作表 + 最高纪录 + 无尽/剧情入口提示，信息完整；首屏可读性良好。
- **暂停页**：鼠标灵敏度、音量、反转纵向视角、画质（自动/高/低）四组设置集中在暂停面板，滑条/勾选/下拉控件直观；ESC 继续提示明确。
- **结算页**：得分/用时/击破/最高连击、评级徽章、历史最高/新纪录、无尽入口按钮层级清楚；死亡（余烬熄灭）与胜利（逃出生天）文案与配色区分明显。
- **小问题（非缺陷）**：
  - 无头/未锁定鼠标时画面中央出现「点击画面锁定鼠标视角」提示；真机首次点击后应消失，建议真人确认提示不会遮挡战斗视野。
  - 暂停/结算覆盖层有约 0.5s 淡入，自动化中已用等待规避；真机体验应无问题。

## 11. v2.0.1 修复构建补充观察（2026-10-19 21:5x）

本轮针对玩家反馈的「翻滚穿地」与「攻击预警可读性」修复做聚焦复验（构建 `BB92E66C…`，v2.0.1）：

1. **翻滚（Dodge）**
   - 手感变化明显：翻滚改为收身翻滚，位移稳定精确（四个朝向均为 3.00m），结束立即回到站立、无落地抖动/反向回弹；头部/膝部全程不穿地（最低 0.142 / 0.388）。
   - 小观察：以整模型包围盒看，翻转峰值时披风/护甲饰件与地面阴影 Sprite 的 AABB 会短暂低于地面（约 -0.2 ~ -0.5）；头/膝与操作判定不受影响，真机视角下是否可见需人工确认（`production/qa/bugs/bug-002-roll-part-clipping.md`，S4 非阻断）。
   - 无敌帧实测 0.017–0.25s，与「手感流派」预期一致；重击/闪避取消后的衔接仍顺畅。
2. **攻击预警（Telegraph）**
   - 可读性提升显著：白色范围底 + 白色描边先给出"危险区域"，红色填充随蓄力从中心铺满，红色填满即出手；石卫 4.0m 圆环、蚀影 3.0m 扇形、Boss 剑雨 2.9m 落点圈均与实际判定范围一致。
   - 末段脉冲与出手白光反馈明确；攻击结束/清场/重开后无残留预警，混战中不会出现"幽灵圈"。
   - 主观建议：真机在赤红 Boss 场景中确认白/红对比是否仍清晰（无头截图下可辨）；若偏暗可再提高亮度。
3. **Boss 突进**：`charge` 命名生效，180s 观察窗口内与剑雨、三连冲击波同场出现，截图已留证。
4. **整体体验**：本轮改动未影响既有战斗/祝福/无尽/结算流程（全量 10 套件 0 FAIL，控制台零错误）；v2.0.1 可作为发布候选，发布前仍建议完成真机性能与音频人工复核。

**v2.0.1 试玩结论：两个玩家反馈问题均已在体验层面修复；无新增阻断/严重问题。**

## 12. v2.0.2 修复构建补充观察（2026-10-19 22:0x）

构建 `60714292…948F89`（v2.0.2），针对 v2.0.1 试玩中记录的「翻滚非核心部件/阴影短暂低于地面」S4 观察项做定向复验：

1. **翻滚观感**：新增角度相关抬升补偿后，收身翻滚的弧线更"贴地但不入地"；可见 Mesh 全程最低 Y 为 **+0.043 ~ +0.063**（四方向），头部 +0.363、膝部 +0.527~+0.547，整段动作没有可见穿地；横向 0.9 收束让翻滚更紧凑，结束仍精确归位（无回弹/无残留缩放）。
2. **中段收剑**：翻滚中段（t≈0.20）长剑隐藏，避免翻转时刃扫入地面；翻滚前与结束后均立即可见。实际游玩中收剑时间很短（约 0.35s 中的 0.345s 窗口），不打断攻击衔接的预期；建议真人确认收剑/出剑的视觉切换是否自然（无头截图仅单帧证据）。
3. **位移**：基础翻滚 3.00m 保持；若构筑选择「疾风」类祝福（`dodgeDistMul ×1.12`）则位移为 3.36m，属设计内加成，手感差异合理。
4. **回归**：08 套件（连击/重击/闪避无敌帧/剑气/烬灭/饮烬/锁定/波次/暂停控件）全 PASS，控制台零错误；本轮改动未影响其他系统。

**v2.0.2 试玩结论：S4 观察项已在实际表现层面消除（可见部件不穿地、收剑自然、位移与归位正确）；无新增问题，可作为发布候选。**
