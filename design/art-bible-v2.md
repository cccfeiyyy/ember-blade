## 1. 视觉身份声明（Visual Identity Statement）

### 1.1 一句话视觉规则
> **世界的底色永远是黑的；只有「仍在燃烧的东西」（玩家、危险、奖励）允许发出高饱和暖光；冷静的青蓝只用于「可被利用的信息」。**

### 1.2 支撑原则与设计测试

| 原则 | 说明 | 设计测试 |
| --- | --- | --- |
| **剪影优先** | 敌人/预警在 3 米外靠形状 + 发光色即可区分 | 当两个特效撞色时，先改形状/大小，而不是提高亮度 |
| **光即语言** | 暖光=威胁/热量/收益；青蓝=可用信息/防御成功；紫=侵蚀/咒术；赤红=二阶段/狂怒 | 当新特效不知用什么颜色时，先问它属于哪类语义 |
| **程序化克制** | 只用几何体、Canvas 纹理、粒子、Sprite 光晕；不引入外部贴图/模型 | 当想要更精致的贴图时，先问能否用参数化几何 + 发光解决 |
| **可读性优先于华丽** | 预警与玩家位置永远比特效更醒目 | 当特效遮挡预警时，降低特效不透明度或密度 |

### 1.3 风格禁令（Style Prohibitions）

- 禁止写实 PBR 贴图、照片纹理、外部模型/动画文件。
- 禁止高饱和粉色/青色大面积铺满画面（破坏黑场层次）；霓虹只用于小面积发光。
- 禁止超过 3 层叠加的全屏后处理（现有叠层已够：vignette / grain / slowmo / hurt / flash）。
- 禁止 UI 使用纯白大面板；面板必须是半透明深色 + 细描边。
- 禁止在战斗中播放遮挡中心视野的持续特效（>0.4s 的全屏不透明覆盖）。

## 3. 形状语言（Shape Language）

| 层 | 形状策略 | 目的 |
| --- | --- | --- |
| 玩家 | 尖顶头盔 + 肩甲斜切 + 长披风 + 细长直剑；整体三角形/楔形剪影 | 在混战中一眼识别「自己」，且指向性明确（面朝方向可读） |
| 蚀影 | 破碎裙摆 + 兜帽锥体 + 细爪 | 快速、飘忽、非人形威胁 |
| 石卫 | 方块躯干 + 巨拳 + 低重心 | 重量感、不可撼动 |
| 咒眼 | 悬浮球体 + 破碎肢体 + 法环 | 远程、脆弱、异质 |
| 爆裂者 | 圆鼓外壳 + 外露发光核心 + 倒计时环 | 「会爆的东西」形状直觉 |
| 无面守望者 | 高大人形 + 无面头盔 + 巨剑 + 破碎披风 | 终局压迫感；二阶段面甲裂开/红光大盛 |
| 竞技场 | 圆形 + 同心符文环 + 放射线 + 断裂立柱 | 仪式感、封闭感、视线引导到中心 |
| 预警 | 扇形/圆环/直线，边缘锐利、内部半透明 | 与场景几何区分，0.2s 内可读 |
| UI | 直角 + 细线 + 菱形符号（◆） | 与竞技场符文同一语言；不抢 3D 画面 |

**英雄形状 vs 辅助形状**：玩家与 Boss 使用最大对比度与最高发光；敌人预警次之；环境装饰（碎石/远景巨影/星空）压到最低对比，只做层次。

### 4.2 稀有度色彩（源码事实，`blessings.js RARITY`）

| 稀有度 | 色值 | 视觉编码 |
| --- | --- | --- |
| 普通 common | `0x9fb4c8`（灰蓝白） | 细边框、无光晕 |
| 稀有 rare | `0x6fe3ff`（青） | 中等边框 + 青光 |
| 史诗 epic | `0xc084ff`（紫） | 粗边框 + 紫色粒子/光晕 |

### 4.3 语义色规则

- **红** = 即将造成伤害（预警）、Boss 二阶段、狂怒、低血；必须配合形状/音效，不能只靠颜色。
- **青蓝** = 可被利用的信息：锁定、势能、弹反成功、稀有祝福。
- **暖橙/金** = 玩家力量、热量、奖励、处决。
- **紫** = 敌方魔法/侵蚀/史诗。
- **白** = 高光/伤害数字/纯净反馈，仅小面积使用。

### 4.4 色盲安全

- 稀有度：颜色 + 文字标签（普通/稀有/史诗）+ 边框粗细三重编码。
- 风格等级：字母（D/C/B/A/S）为主，颜色为辅。
- 敌人预警：扇形/圆环形状差异 + 前摇时长 + 音效（`teleport` / `roar`）区分，不只靠红/紫。
- 低血警告：颜色 + 文字「生命垂危」+ 脉动频率。

## 5. 角色设计方向（Character Design Direction）

### 5.1 玩家角色（无名剑魂）
- 视觉原型：破碎骑士——暗色板甲 + 红色飘带 + 单剑；无面部特征（面甲发光缝隙）。
- 识别特征：披风与飘带提供运动可读性；剑身发光条指示朝向与攻击节奏。
- 姿态风格：写实偏夸张的武士动作，前摇清晰、收招干脆；受击/破防有明显失衡。
- 细节层级：游戏镜头距离 5.8m，细节以「肩甲轮廓、披风分段、剑身发光」为主，不做面部微表情。

### 5.2 敌人识别规则

| 敌人 | 一眼识别特征 | 发光语言 |
| --- | --- | --- |
| 蚀影 | 破碎裙摆 + 两点红紫眼焰 | 红紫裂缝 |
| 石卫 | 巨型方块肩甲 + 胸口熔岩核心 | 橙红裂纹 |
| 咒眼 | 悬浮 + 环绕法环 + 紫眼 | 紫色咒光 |
| 爆裂者 | 二十面体圆鼓外壳 + 7 根尖刺 + 熔火裂隙 + 4 条短腿；橙黄发光核心/独眼 | 橙黄脉冲 + 倒计时红环 |
| 精英 | 脚下光环 + 头顶词缀图标 + 体型放大 12% | 青白/蓝紫/赤红 |
| Boss | 无面 + 巨剑 + 破碎披风 + 双角 | 红色眼焰 |

### 5.3 LOD 哲学
- 所有模型为基础几何体组合（Box/Cylinder/Cone/Sphere/Icosahedron），单角色 10–40 个 mesh；不追求多级 LOD，靠「远景巨影用纯色低模」控制成本。
- 阴影仅主光投射（PCFSoft 1024），低画质档关闭阴影。

## 6. 环境设计语言（Environment Design Language）

- **建筑风格**：环形仪式竞技场——断裂石柱、同心法阵、放射符文、裂隙与余烬。风格融合「古代祭坛 + 废墟 + 深渊」，无具体文明指涉。
- **材质哲学**：程序化 Canvas 纹理（2048² 地面：基础色 + 自发光贴图）；MeshStandardMaterial + 自发光；粗糙度高、金属度低，避免塑料感。
- **道具密度**：中心战斗区完全空白；装饰集中在半径 30m 外（14 根立柱、16 块悬浮石、9 座远景巨影、1400 点星空、月亮与光晕），形成「空舞台 + 密集远景」对比。
- **环境叙事**：立柱上的符文与火盆暗示「曾经有人在此守望」；Boss 二阶段的赤红竞技场暗示「竞技场本身在燃烧」；无需文字。
- **动态环境**：余烬粒子持续上升、灰烬飘落、火盆闪烁、悬浮石缓慢旋转、月光呼吸；一切都在微动，但幅度不足以干扰战斗。

### 6.1 赤红竞技场（Boss 二阶段专属，源码事实 `W.setCrimson`）
- 通过 `W.setCrimson(on)` 参数切换，不重建网格。开启时：
  - 背景 `0x160409`、雾 `0x24060a`；
  - 半球光天空 `0x8a4a5a` / 地面 `0x160406`；月光颜色 `0xff9a88`、强度 1.55；背光 `0x8a2a3a`（0.7）；轮廓光 `0xa83a3a`；
  - 月面 `0xff9a8a`、月晕 `0xff3a20`、余烬点光 `0xff2a12`、玩家剑光 `0xff3a10`；
  - 地面自发光 `0xff6040`、强度 0.6；火盆光 `0xff2a10`、火焰 `0xff3a18`。
- 保留玩家与预警的对比度：Boss 与危险预警仍用最亮红/白边缘，环境红不得盖过预警。
- 关闭时完整还原（背景/雾/灯光/月面/月晕/余烬光/地面自发光/火盆/剑光）；重开/胜利/进入无尽必须调用，避免污染标题页。

## 7. UI / HUD 视觉方向

- **屏幕空间 HUD**（非 diegetic）：半透明深色面板 + 细暖色描边 + 菱形符号；与竞技场符文同语言但不抢 3D 画面。
- **字体**（源码事实）：
  - 中文 UI：`"Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", "Hiragino Sans GB", sans-serif`（`--font-cn`）
  - 标题/电影感文字：`"STSong", "SimSun", "Songti SC", "Noto Serif SC", serif`（`--font-display`）
  - 数字/键帽/英文 kicker：`"Consolas", "SFMono-Regular", monospace`（`--font-mono`）
- **字号层级**：得分 30px / 连击 52px / 风格字母 40px+ / 波次 22px / 标题 42px+ / 按钮 19px / 说明 10–13px。
- **图标风格**：单字汉字（祝福图标「锋/重/疾/…」）、菱形 ◆、细线键帽；不使用写实图标。
- **动效**：
  - UI 出现：短促淡入 + 轻微上浮（120–200ms）；重击类提示用「砸入 + 震动」。
  - 风格升级：字母放大 1.2 倍回弹 + 光晕；S 级加金色余烬粒子。
  - 祝福卡：悬停上浮 6px；选择时放大 + 稀有度粒子。
- **祝福卡视觉**：深色卡面 + 稀有度描边/光晕 + 单字 icon + 名称（宋体）+ 效果（雅黑）+ 风味（斜体/灰青）+ 层数徽标；史诗卡加入缓慢紫光扫过。
- **风格评价视觉**（源码事实 `style.css`）：右上风格盒；D 灰白（`rgba(200,208,222,.55)`）、C 青（`#9fe8ff`）、B 绿（`#8dffc0`）、A 橙（`#ffbe6b`）、S 金渐变（`#fff6d8 → #ffb84d 60% → #ff6a2a`）并带 `drop-shadow` 光晕；升级时 `styleRankPop` 放大 1.55 倍回弹（0.55s）。
- **风格条**：`#style-fill` 使用 `linear-gradient(90deg, #3a6a8a, #6fe3ff 55%, #ffe6a0)` + 青色外发光；宽度过渡 0.18s。
- **祝福卡**：`.blessing-card` 宽 250px、最小高 310px；含左上数字键 `card-key`、稀有度标签 `card-rarity`、单字 icon、名称、效果、带书名号的风味；悬停上浮 8px；选中播放 `cardPick`（0.38s）。稀有度边框/光晕：普通 `rgba(159,180,200,.65)`、稀有 `rgba(111,227,255,.8)`、史诗 `rgba(192,132,255,.9)`。
- **已获祝福 chip**：27×27 单字方块，普通 `#c3d2e4`、稀有 `#9ff2ff`、史诗 `#e2c2ff`；叠加层数显示在右下角小字（`×N` 效果）。

## 8. 资产标准（Asset Standards）

| 项 | 标准 |
| --- | --- |
| 资产来源 | 100% 程序化：几何体 + Canvas 生成纹理 + Sprite 光晕 + 粒子系统 + WebAudio 合成 |
| 外部文件 | **零**（无贴图/模型/音频/字体文件；字体使用系统字体） |
| 单文件体积 | `index.html` ≤ 1 MB（v1 约 808 KB；v2 目标 ≤ 950 KB） |
| 纹理 | Canvas 最大 2048²（地面），其余 64–256²；无 mipmap 外部文件 |
| 几何预算 | 玩家 ~30 mesh、普通敌人 ~15–25、Boss ~60、场景装饰 ~60；总 draw call 控制在数百级 |
| 阴影 | 仅主方向光，1024²，PCFSoft；低画质关闭 |
| 渲染设置 | `outputEncoding = sRGBEncoding`、`ACESFilmicToneMapping`、`exposure 1.08`、`Fog(0x05070d, 30, 130)`、像素比 ≤1.75（低画质 0.75） |
| 命名规范 | 源码内 `buildXxx` 工厂、`createXxx` 工具、颜色常量用语义命名（`ember/cyan/blood/violet`） |
| 粒子上限 | 复用粒子池（v1 已实现），同屏粒子数量由画质档与事件频率控制 |
| 音频 | 全程序化 WebAudio：单文件、无采样；SFX 峰值增益 ≤0.5，音乐层增益克制避免削波 |

## 10. v2 音频方向（程序化音乐与音效）

### 10.1 音乐层（源码事实，`audio.js`）
- 采样率/合成：WebAudio 实时合成，无采样；2 秒白噪声缓冲。
- 模式：`none` / `title` / `battle` / `boss` / **`boss2`**；未知模式安全降级为 `battle`。
- 节拍：`boss2` **100 BPM**，其余 84 BPM（八分音符步进，32 步循环）。
- 和声：D 小调五声为主；`boss2` 增加密集鼓点、低音铜管与不协和层。
- 强度：`setIntensity(0..1)` 随波次提升（战斗 `n/5`），影响鼓点/滤波/旋律密度。
- 音量：标题 0.55 级、战斗 1.0 级（音乐增益目标 0.5，淡入 0.8s）。

### 10.3 混音原则
- SFX 与音乐分轨（`sfxGain 0.6` / `musicGain` 目标 0.5），弹反/处决等关键反馈在 SFX 层优先，不被音乐掩盖。
- 同帧多个同类音效合并（如多段命中），避免爆音；单帧新增音源数量由事件频率自然限制。
