## 1. 概览

本系统负责 v2 的敌人侧压力：在 v1 三种基础敌人（蚀影/石卫/咒眼）之上增加

1. **爆裂者（`detonator`）**：快速接近后自爆的范围威胁；
2. **精英词缀**：迅捷 / 护盾 / 狂怒；
3. **掉落拾取**：治疗余烬 / 势能碎片。

设计目的：让每一波的「先打谁、怎么打」成为有意义的决策。

## 4. 敌人行为详解

### 4.1 蚀影 Wraith（v1 逻辑保留）

| 项 | 值 |
| --- | --- |
| 状态机 | `chase → windup(0.55s) → strike → recover(0.62s) → chase` |
| 追击 | 距离 >2.1m 直线追击；近身环绕 |
| 攻击 | 红紫扇形 2.9m / ±0.85rad；突进 9 单位挥爪，伤害 12 |
| 冷却 | 1.3–2.3s |
| 硬直 | 重斩命中 → stagger 0.45s |

### 4.2 石卫 Golem（v1 逻辑保留）

| 项 | 值 |
| --- | --- |
| 状态机 | `chase → windup(0.95s) → strike → recover(1.15s)` |
| 攻击 | 红圆环 3.7m；砸地冲击波，距离 <4.0 受 24 伤 |
| 冷却 | 1.4–2.4s |
| 硬直 | 重斩命中 → stagger 0.32s |

### 4.3 咒眼 Hexer（v1 逻辑保留）

| 项 | 值 |
| --- | --- |
| 状态机 | `chase → windup(0.65s) → strike(三连射) → recover(1.0s)` |
| 走位 | 距离 <8.5m 后退，>13.5m 靠近，否则环绕 |
| 攻击 | 玩家脚下紫圈预警；三连弹幕（间隔 0.14s、速度 14、伤害 10、半径 0.6、寿命 3.5s） |
| 冷却 | 1.8–2.8s |
| 交互 | 弹幕可被 Q 格挡减伤 / 弹反免伤（当前弹反不反弹伤害） |

### 4.4 爆裂者 Detonator（v2 新增，源码事实）

| 项 | 值 |
| --- | --- |
| 生命 / 半径 / 速度 | 56 / 0.60 / 4.9 |
| 行为 | `chase`：距离 >1.5m 追击；累计 `chargeTimer`。**距离 <2.7m 或 `chargeTimer > 6.5s`** → `windup` |
| 倒计时 | `windupDur = 0.85s`，红色圆环半径 3.8，播放 `detonate`（滴答） |
| 自爆 | `detonateEnemy`：半径 3.8 冲击波；玩家距离 <3.8 受到 `e.dmg`（基础 26 × 波次/精英倍率）；对**玩家**结算（可被正面格挡减伤） |
| 自爆结果 | 不经过 `killEnemy`：**无击杀分/连击/掉落概率**；原地必掉 1 个「势能碎片」拾取物（+16 势能，12s 寿命） |
| 被击杀 | 正常走 `killEnemy`：得分 260×波次/精英倍率、正常连击/势能/风格、无害殉爆特效（无伤害）、按普通概率掉落 |
| 处决 | 低血进入破绽后可被处决（即时斩杀，走 `killEnemy`，正常掉落） |
| 视觉 | 二十面体圆鼓外壳 + 7 根尖刺 + 熔火裂隙 + 4 短腿 + 橙黄发光核心/独眼；出生传送门 `0xffb040` |
| 出现波次 | 第 4 波 2 只、第 5 波 1 只、无尽波次由 `makeEndlessWave` 轮换 |

## 5. 精英词缀（Elite Affixes，源码事实）

### 5.1 生成规则

| 项 | 规则 |
| --- | --- |
| 主流程概率 | 第 3 波 10%；第 4 波起 16%（`getWaveDef`） |
| 无尽概率 | `min(0.55, 0.10 + k × 0.05)`，k = n−5 |
| 判定 | 每个非 Boss 生成点独立掷骰（`startWave` 中 `Math.random() < eliteChance`） |
| 数量上限 | 无硬上限（由概率与波次生成数量自然限制；无尽最高 16 敌人） |
| 词缀数量 | 每个精英 **1 种**（`U.choice(['swift','shield','fury'])`） |
| 视觉 | 脚下光环颜色 = 词缀色；体型 `finalScale = 1.12`；出生播报「精 英 · {词缀}」+ `audio.sfx('eliteSpawn')` |
| 得分 | `scoreMul × 2` |
| 掉落 | `guaranteedDrop = true`（见 §6） |

### 5.2 词缀表

| 词缀 | 光环色 | 生命倍率 | 速度倍率 | 伤害倍率 | 特殊机制 |
| --- | --- | --- | --- | --- | --- |
| **迅捷** | `0xffd36b`（金） | ×1.35 | ×1.4 | ×1.0 | 更快逼近、更快起手 |
| **护盾** | `0x6fe3ff`（青） | ×1.7 | ×1.0 | ×1.0 | `shieldHits=1`：**第一次被击伤害 ×0.3 并破盾**；破盾有闪光/粒子/`block` 音效与「护盾破碎」提示；之后正常结算 |
| **狂怒** | `0xff5a3a`（赤） | ×1.5 | ×1.15 | ×1.45 | 更高伤害与移速 |

> 企划原案「护盾=40% 生命护盾、破盾不恢复、弹反直接碎盾」在实现中简化为「首击减伤 70% 并破盾」；重斩/弹反不必强制，任意首击即可破盾（以实现为准）。

### 5.3 与既有系统交互

- **弹反**：精英攻击可被弹反；弹反使非 Boss 敌人 stagger 1.2s 并受 22 反伤；护盾精英的护盾在首击（含弹反反伤）时即破。
- **处决**：低血（24%+祝福）进入破绽，任意近战/剑气命中即斩杀（走正常击杀掉落）。
- **祝福**：灼烧/风暴/荆棘/噬魂等按 `P.mods` 生效。

## 6. 掉落与拾取（源码事实）

### 6.1 掉落规则 `dropLoot(e)`

| 敌人 | 掉落 |
| --- | --- |
| Boss | 4 件：治疗 ×2（每次 +14）、势能 ×2（每次 +20），位置随机散布 ±2 |
| 精英（`guaranteedDrop`） | 治疗 +12、势能 +20（各 1 件） |
| 普通敌人 | 28% 概率掉治疗 +9；否则 22% 概率掉势能 +15；二者互斥 |
| 爆裂者自爆 | 不经过 `dropLoot`；固定掉势能 +16（12s 寿命） |

### 6.2 拾取物

| 项 | 规则 |
| --- | --- |
| 类型 | 治疗余烬（绿 `0x7dffb0`）/ 势能碎片（橙 `0xffc860`） |
| 默认数值 | 治疗 +10 / 势能 +18（仅当 `amount` 未指定时） |
| 存在时间 | 普通 20s；爆裂者掉落 12s |
| 生成上限 | 场上同时 ≤26 个（超出不再生成） |
| 磁吸 | 距离 <5.2m 时以 `7×(1−d/6)+1.5` 速度飞向玩家 |
| 拾取半径 | 1.25m |
| 漂浮/旋转 | 上下浮动 ±0.16、核心旋转 |
| 将消失提示 | 剩余 <3.5s 时闪烁 |
| 拾取反馈 | 治疗飘绿字 `+N`；势能飘「势 +N」；`audio.sfx('pickup')`；小粒子爆发 |
| 清波处理 | **不自动结算**：未拾取掉落保留到寿命结束（当前无尽/主流程均如此） |

### 6.3 资源曲线意图

- 普通敌人掉落较克制（约 28%/22%），精英/Boss 提供确定资源；
- 爆裂者自爆给势能（对「躲开爆炸」的补偿），被击杀则走概率掉落；
- 治疗量（9–14）低于药剂（40），属于战斗中的小额续航。

## 7. 波次与缩放

### 7.1 主流程波次（源码事实 `WAVES`）

| 波次 | 组成 |
| --- | --- |
| 第 1 波 | 蚀影 ×3 |
| 第 2 波 | 蚀影 ×4、石卫 ×1 |
| 第 3 波 | 蚀影 ×3、石卫 ×2、咒眼 ×2 |
| 第 4 波 | 蚀影 ×4、石卫 ×3、咒眼 ×3、**爆裂者 ×2** |
| 第 5 波 | 蚀影 ×2、**爆裂者 ×1**、Boss ×1 |

波次缩放（`getWaveDef`）：第 1–2 波 ×1；第 3 波起生命 `1+(n−2)×0.06`、伤害 `1+(n−2)×0.04`；精英概率第 3 波 10%、第 4 波起 16%。Boss 生命同样乘 `hpMul`（第 5 波 ×1.18 → 968）。

### 7.2 无尽波次（`makeEndlessWave`）

见 `boss-phase2-endless.md` §4.2。要点：第 6 波起、每 5 波 Boss、敌人数量 `min(16, 4+floor(k×0.9))`、生命/伤害/得分分别 ×(1+0.11(k−1)) / ×(1+0.065(k−1)) / ×(1+0.16(k−1))、精英概率最高 55%。

### 7.3 生成规则

| 项 | 规则 |
| --- | --- |
| 普通敌人位置 | 围绕场地外环：半径 17–24，角度均分 + 随机 ±0.4 |
| Boss 位置 | 玩家前方 13.5m |
| 出生延迟 | `min(6.5, 0.75 + idx × 0.24)` 秒 |
| 出生表现 | 传送门（颜色按敌人/精英）+ 从地下升起 + 缩放 `easeOutBack` |
| 波次缩放传递 | `opts.hpMul/dmgMul/scoreMul/elite/eliteKind` → `createEnemy` |

## 8. 公式

```
// 精英
hpMul    = baseHp × waveHpMul × eliteCfg.hpMul
dmgMul   = baseDmg × waveDmgMul × eliteCfg.dmgMul
score    = baseScore × waveScoreMul × (elite ? 2 : 1)
finalScale = elite ? 1.12 : 1

// 爆裂者
explosionRadius = 3.8
explosionDamage = e.dmg (基础 26 × waveDmgMul × eliteDmgMul)
selfDestructDrop = momentum +16
killedDrop = dropLoot 普通概率

// 掉落
普通: 28% heal +9；else 22% momentum +15
精英: heal +12 与 momentum +20 各 1
Boss: heal +14 ×2 与 momentum +20 ×2
```

## 9. 边界情况（实现行为）

| 场景 | 行为 |
| --- | --- |
| 爆裂者倒计时中被击杀 | 正常死亡（无害殉爆特效、无伤害），按概率掉落 |
| 爆裂者自爆 | 不触发击杀分/连击；必掉势能 +16；对玩家伤害按来源正面可格挡 |
| 多个爆裂者连锁 | 自爆伤害只结算玩家，不伤害其他敌人（当前实现无友伤） |
| 护盾精英首击 | 伤害 ×0.3 并立刻破盾；后续正常伤害 |
| 精英被处决 | 走 `executeEnemy` → `killEnemy`，正常掉落（含 guaranteedDrop） |
| Boss 掉落 | 主流程击杀即胜利，拾取物意义有限；无尽 Boss 击杀后可拾取 |
| 掉落上限 | 场上 >26 时不再生成新掉落 |
| 拾取物在波次切换 | 保留，不自动结算；Boss 战前可回头拾取 |
| 拾取时生命已满 | 治疗量被浪费（仍消耗拾取物），显示 +0 不飘字 |
| 势能已满 | 势能拾取仍消耗（`addMomentum` clamp 到上限） |

## 13. UI 要求

- 敌人血条（`#enemy-bars`）：受伤后显示；精英加词缀色/标记；破绽加金色高亮；爆裂者血条高度 1.7（避免与倒计时重叠）。

- [ ] AC-6：普通敌人掉落概率与数值符合 §6.1；拾取后资源正确增加。
- [ ] AC-7：拾取物磁吸/半径/寿命/上限/闪烁符合 §6.2。
- [ ] AC-8：主流程/无尽波次组成与缩放符合 §7。

## 15. 开放问题

1. 爆裂者自爆无友伤，是否削弱了「引怪炸怪」的策略深度？
2. 普通掉落概率（28%/22%）是否过低？QA 需观察 5 波及无尽前 10 波的资源压力。
3. 未拾取掉落不在清波时结算，是否会让玩家在祝福选择前被迫「回头捡东西」？当前暂停语义下掉落会保留。
4. 精英无数量上限，无尽 16 只敌人最多可能 16 个精英（概率 55%）；是否需要硬上限（如 3）？
