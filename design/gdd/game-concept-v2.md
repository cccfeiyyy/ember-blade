## 2. 电梯陈述（Elevator Pitch）

> 你是永夜竞技场里最后一缕未熄的剑魂。斩尽侵蚀者、弹反它们的利爪与咒弹、在风格评价攀上 S 的瞬间斩杀无面守望者——然后，选择继续坠入更深的回响。

区别句：**这是一款「用弹反把敌人的攻击变成自己的回合」的 3D 剑斗游戏，并且它把「打得漂亮」直接换算成构筑资源与评分。**

## 3. 核心幻想 · 独特钩子

### 3.1 核心幻想（Core Fantasy）
「预判—化解—反击」的循环快感：敌人的每一次攻击都是可读、可弹反、可转化为优势的。玩家不是被动躲伤害，而是在危险降临前 0.2 秒按下格挡，把致命一击变成自己的处决开场。

### 3.2 独特钩子（Unique Hook）
**弹反即构筑燃料。** 精准弹反、处决与高风格评价不仅提供伤害窗口，还直接加速势能、提高得分，并决定每波后「回响祝福」三选一的成长速度。技术上限与构筑上限由同一套操作驱动——越敢拼，成长越快。

### 3.3 一句话差异化
- 对《只狼》：保留弹反的读招博弈，但把「架势条」替换为「风格评级 + 构筑三选一」，单局更短、更街机化。
- 对《鬼泣》：保留风格评价，但目标是「在 5 波内尽快到 S 并维持」，而非长连段表演。
- 对 Roguelite：祝福数量少（22 条）但叠加上限清晰，构筑靠「拿什么 + 何时拿」而非海量随机池。

## 4. 设计支柱与反支柱

### 4.1 支柱（Pillars）

| # | 支柱 | 一句话定义 | 设计测试 |
| --- | --- | --- | --- |
| P1 | **危险必须可读** | 所有伤害都有前摇、预警与可执行的应对 | 若一个攻击无法在 0.4 秒内被识别并反应，则降低其速度或增加预警，而不是加数值 |
| P2 | **弹反改写回合** | 精准弹反/处决必须实质改变战斗节奏，而非只加伤害 | 若弹反收益低于「多砍两刀」，则提高其硬直、势能或风格收益 |
| P3 | **漂亮即成长** | 风格评价与祝福获取强关联，操作上限决定构筑上限 | 若一个构筑不依赖任何操作仍有同等收益，则削减其被动强度 |
| P4 | **再来一局** | 单局短、信息公开、结算清晰，失败后 3 秒内想再开一局 | 若结算页信息超过 8 项或重开流程超过 2 次点击，则简化 |
| P5 | **单文件即产品** | 零安装、零外部资源、断网可玩，一切美术/音频由代码生成 | 若新增内容需要外部素材或构建链依赖，则改为程序化实现或砍掉 |

### 4.2 反支柱（Anti-Pillars）

- **不做开放世界/关卡探索**：竞技场是舞台，不是地图；范围扩张会稀释 8–12 分钟单局节奏。
- **不做装备/背包/经济系统**：祝福即成长，不做商店、金币、词条洗练。
- **不做多人/排行榜服务**：无尽纪录仅存本机 `localStorage`，无网络、无账号。
- **不做叙事分支与对话**：世界观通过标题页文案、Boss 阶段名与祝福风味文案传递。
- **不做精确平台适配**：只保证桌面 Chromium 系浏览器；移动端与触屏不在范围。

## 5. 玩家动机分析（Self-Determination Theory）

| 需求 | 本作如何满足 | v2 强化手段 |
| --- | --- | --- |
| **Autonomy 自主** | 每波后三选一、Q 格挡与闪避两种防御选择、重斩/剑气资源取舍 | 祝福构筑产生明显流派差异（连击流/弹反流/处决流/灼烧流） |
| **Competence 胜任** | 读招—弹反—处决的技术闭环；风格评级即时反馈 | 风格等级、弹反慢动作与音效强化「我变强了」的证据 |
| **Relatedness 关联** | 与「无面守望者」的循环宿命关系；竞技场人格化文案 | Boss 二阶段阶段名（回响形态/终焉形态）与赤红竞技场叙事 |

**主要玩家类型（Bartle）**：Achievers（评级/纪录/无尽波数）为主，Killers（高手向连击与弹反）为辅；Explorers 通过祝福组合获得有限探索乐趣。**不是**为 Socializers 设计。

## 6. MDA 分析

### 6.1 机制（Mechanics）
- 三段轻斩 + 重斩 + 闪避无敌帧 + 剑气 + 势能必杀 + 饮烬，构成基础战斗资源循环。
- v2 新增：Q 格挡/精准弹反（实现 **0.20s** 窗口）、处决破绽、风格评价 D→S、回响祝福（22 条、三档稀有度、可叠加、`mods` 统一聚合）、精英词缀、爆裂者自爆 AOE、掉落拾取、Boss 50% 二阶段与 25% 狂怒、无尽模式、设置持久化。
- 波次：主流程 5 波（第 5 波 Boss），每波清场奖励生命/药剂/得分；胜利后可进入无尽模式，波次无上限。

### 6.2 动态（Dynamics）
- **风险—收益**：贪刀→被打断连击/掉风格；保守→风格衰减、势能增长慢。
- **弹反博弈**：0.20s 窗口让「早按」变成普通格挡（减伤但耗体力），「晚按」直接吃伤害——形成可学习的时机曲线。
- **构筑节奏**：开局 1 选 + 每波清场后 1 选（主流程共 5 次；无尽每波 1 次），祝福叠加上限制造「专精还是补短板」的取舍。
- **无尽压力曲线**：敌人数量/血量/伤害随波次增长，每 5 波 Boss，逼迫构筑在 10 波后成型。

### 6.3 美学（Aesthetics）
- **Challenge**（核心）：评级、无伤清波、无尽纪录。
- **Sensation**：金属铿锵的弹反音、命中停顿、慢动作、屏幕震动、赤红竞技场。
- **Fantasy**：孤独剑魂对抗无尽侵蚀的宿命感。
- **Expression**：风格评级与祝福组合即玩家的自我表达。

## 7. 核心循环

### 7.1 30 秒循环（战斗决策）
```
观察预警 → 选择应对（走位/闪避/格挡/弹反）→ 命中/弹反成功 → 连击与风格上涨 → 势能积累
        ↑                                                        ↓
        └────────── 敌人反击 ← 处理下一波威胁 ← 释放烬灭/处决 ←──┘
```

### 7.2 单波循环（约 60–120 秒）
清场 →「区域肃清」奖励（生命 +20、药剂 +1、得分 420×波次、无伤额外 +300）→ 回响祝福三选一 → 下一波。

### 7.3 单局循环（8–12 分钟）
标题 → 第 1 波 → 祝福成长 ×4 → 第 5 波 Boss（50% 二阶段、25% 狂怒）→ 胜利结算（S/A/B/C 评级 + 用时/击破/最高连击）→「再战一次 / 无尽回响 / 返回标题」。

### 7.4 长线循环（无尽模式）
胜利后进入无尽 → 每波递增 → 每 5 波 Boss → 死亡结算显示到达波数与最高纪录 → 刷新 `localStorage` 纪录后回标题看到新纪录，产生「再冲一层」动机。

## 9. v2 范围与优先级

### 9.1 MVP（必须交付，全部已实现）

### 9.2 完整愿景（本次若有余量）
- 祝福流派专属视觉反馈（如灼烧层数图标）。
- 无尽模式 Boss 词缀变体与更高波次压缩。

## 10. 风险与缓解

| 风险 | 等级 | 说明 | 缓解 |
| --- | --- | --- | --- |
| 祝福数值与基础战斗失衡（滚雪球或无用） | 高 | 22 条乘法叠加可能产生极端组合 | 乘法项上限收敛、叠加上限、史诗唯一；以「是否让 5 波变简单」为验收问题 |
| 弹反窗口手感（企划 0.18s / 实现 0.20s）过严/过松 | 高 | 浏览器帧率波动影响判定 | 按帧推进的固定步长逻辑（现有 loop 已限幅 0.05s）；窗口可被祝福调节；保留普通格挡作为兜底 |
| 风格评价刷分退化策略 | 中 | 只靠高连击维持 S | 衰减速率 + 受击惩罚 + 处决/弹反权重更高，鼓励主动博弈 |
| Boss 二阶段性能（赤红竞技场 + 剑雨） | 中 | 新增粒子/灯光可能掉帧 | 复用现有粒子池与画质自适应；赤红阶段以材质/灯光参数切换为主，不新增常驻网格 |
| 单文件体积膨胀超过 1 MB | 中 | 新代码约 +40–60 KB | 构建脚本自动统计；无外部资源；当前 904 KB |
| 无尽模式数值失速或无限拖时间 | 中 | 波次线性增长可能被高构筑碾压 | 每 5 波 Boss 硬门槛 + 敌人数量/血量增长率分段调参 |
| 文档与实现漂移 | 中 | 设计与实现并行推进 | 附录 A 对齐检查清单；发版前以源码/构建产物为准（已完成） |

## 12. 视觉身份锚点（Art Bible Seed）

- **方向名**：**「余烬暖橙 · 冷月青蓝 · 深渊黑」的程序化暗黑幻想**
- **一句话视觉规则**：世界的底色永远是黑的；只有「仍在燃烧的东西」（玩家、危险、奖励）允许发出高饱和暖光，冷静的青蓝只用于「可被利用的信息」（锁定、势能、弹反）。
- **支撑原则**：
  1. **剪影优先**：所有敌人与预警在 3 米外必须靠形状与发光色区分（P1 危险可读）。
  2. **光即语言**：暖光 = 威胁/热量/收益；青蓝 = 可用信息/防御成功；紫 = 侵蚀/咒术；赤红 = 二阶段/狂怒（P1/P2）。
  3. **程序化克制**：一切视觉由几何体 + Canvas 纹理 + 粒子构成，不引入外部贴图；用有限的调色板和光强对比制造层次（P5）。
- **色彩哲学**：黑场 + 单一主光源（冷月）+ 玩家自发光（余烬）+ 危险高饱和（红/紫/橙）。UI 沿用此语言：面板半透明深色、描边暖橙、信息文字青蓝。

## 14. 术语表

| 术语 | 含义 |
| --- | --- |
| 回响祝福 / Echo | 每波后三选一的构筑增益，22 条，三档稀有度，可叠加，`mods` 聚合生效 |
| 势 / Momentum | 0–100 资源，命中/击杀/弹反积累，满后可放「烬灭」 |
